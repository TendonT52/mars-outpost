# Mars outpost

A Scratch game for children of 7 to 12.
The player keeps a small base on Mars alive until the rescue comes.
The player controls power, water, food, oxygen and the radiation dose, and sleeps to move the time on.
An AI ship computer speaks to the player and tells the next thing to do.

## The file

`Mars outpost.sb3` is the Scratch 3 project.
It has 192 sprites and the stage.

## How to open it

1. Download `Mars outpost.sb3`.
2. Open the Scratch editor and select **File > Load from your computer**.

The game uses the custom extension `mastra` for the ship computer and its voice.
The standard Scratch editor does not have this extension.
The editor can show a warning, and the computer does not speak.
The full game needs the custom Scratch editor and the game server of the project.

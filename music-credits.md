# Music credits

The tool `game/tools/fetch-music.mjs` makes each music track of the Mars game from the sources below.
Each source has the license CC0 1.0 (public domain) on its OpenGameArt page.
So the school can copy and share the game with the music.
The authors do not ask for credit, but we give it here.

All tracks are MP3, 22050 Hz, mono, 96 kbps.
The tool sets each track to -18 LUFS integrated loudness.
Each loop track has a 5 ms fade at the start and at the end, so a restart in Scratch makes no click.

## title

- Source: <https://opengameart.org/content/calm-ambient-3-lifewave-2k>
- Original title: "Calm Ambient 3 (Lifewave 2k)", by The Cynic Project (cynicmusic), from the game Pixelsphere.
- License: CC0.
- Changes: we cut a loop of 39.4 s (from 24.6 s in the source) and crossfade the end into the start for 1.5 s.
  We mix the stereo to mono and set the loudness.

## outside

- Source 1: <https://opengameart.org/content/wind1>
- Original title: "wind1" (file `wind1.wav`), by Luke.RUSTLTD.
- Source 2: <https://opengameart.org/content/calm-piano-1-vaporware>
- Original title: "Calm Piano 1 (Vaporware)", by The Cynic Project (cynicmusic), from the game Pixelsphere.
- License: CC0 (both sources).
- Changes: we cut a loop of 39.0 s from each source.
  The wind loop has a crossfade of 3 s, and the piano loop has a crossfade of 1.5 s.
  We make the piano quiet and dark with a low pass filter at 1600 Hz, so it sounds far away.
  We mix the two sources to mono and set the loudness.

## minigame

- Source: <https://opengameart.org/content/crystal-cave-song18>
- Original title: "Crystal Cave (song18)", by The Cynic Project (cynicmusic), from the game Pixelsphere.
- License: CC0.
- Changes: the source is a loop of 20 bars at 100 BPM.
  We cut it at the end of bar 20 (48.0 s) and add the release after that point onto the start.
  We mix the stereo to mono and set the loudness.
- Note: the plan asks for 25 to 35 s.
  This track is 48.0 s, because a shorter cut of this source does not loop well.
